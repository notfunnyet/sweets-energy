# 🍓 Sweets Energy [SITE EXEMPLO PARA PORTFÓLIO, NÃO É UMA EMPRESA REAL!]

> Energia com sabor de doce. Muito sabor, muita disposição.

**Sweets Energy** é um projeto de bebida energética com foco em sabor: uma linha de energéticos frutados, coloridos e refrescantes, pensada para quem quer energia para o dia a dia sem abrir mão de uma bebida gostosa de verdade.

---

## 📌 Sobre o projeto

O mercado de energéticos costuma priorizar a "força" e deixar o sabor em segundo plano. A **Sweets Energy** inverte essa lógica: o sabor vem primeiro, com perfis doces e frutados inspirados em balas, sorvetes e limonadas, sem perder o papel principal do produto, que é dar energia.

**Proposta de valor**

- Sabores marcantes e fáceis de gostar, mesmo para quem não é fã de energético tradicional
- Identidade visual jovem, colorida e divertida
- Linha enxuta com três sabores bem definidos
